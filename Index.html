Your YouTube app

Paste the address of the YouTube unblocked app you already made. Toolzy will try to show it here. If it doesn't allow embedding, use “Open separately”.

Local data

Conversation history and settings stay in this browser. Clearing browser site data can remove them.

Security note: because this is a personal browser-only version, the API key is stored locally rather than on a server. Anyone with access to your browser profile could access it. A server-side key is better if you later share Toolzy.
